# SQL Directory

Author: CJ Shane

This directory separates the canonical schema snapshot from historical and future SQL changes.

## Files And Folders

- `schema.sql`: exact schema-only dump generated by `scripts/export_live_schema.ps1`.
- `history/`: SQL files that document prior database work or audit operations.
- `migrations/`: future SQL changes that should exist before they are applied to a live database.

## Rules

- Do not hand-edit `schema.sql`; regenerate it from the live database with `pg_dump`.
- Put new intentional DB changes in `migrations/` before applying them.
- Keep one-off generated dumps in `.db_dumps/` or another ignored local path.
